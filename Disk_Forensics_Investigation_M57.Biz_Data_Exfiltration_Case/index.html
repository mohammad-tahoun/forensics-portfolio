CASE #002 • NETWORK & MALWARE TRAFFIC FORENSICS

Network Forensics Investigation: Malicious Traffic & C2 Analysis

Packet capture (PCAP) forensic examination of 2022-03-21-traffic-analysis-exercise.pcap to identify compromised host details, malicious HTTP/DNS communications, and extract payload artifacts.

Download Full Forensic Report (PDF)

// 01. Forensic Methodology & Packet Inspection

01. Victim Host Profiling

Analyzed DHCP, Kerberos (KRB5), and endpoint statistics in Wireshark to pinpoint the compromised host's IP, MAC, hostname, and Active Directory user.

02. DNS & HTTP Traffic Triage

Filtered dns and http.request streams to uncover suspicious domain lookups and outbound GET requests to external infrastructure.

03. HTTP Object Carving

Extracted transferred GZIP payload objects directly from TCP stream #498 using Wireshark's Export HTTP Object utility.

04. Threat Intelligence & Hashing

Computed the artifact's SHA-256 hash via sha256sum and validated malicious URLs and C2 IPs against VirusTotal.
