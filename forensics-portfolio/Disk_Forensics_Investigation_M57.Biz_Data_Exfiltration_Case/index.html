CASE #001 • DISK & EMAIL FORENSICS

Disk Forensics Investigation: M57.Biz Data Exfiltration Case

A complete dead-box digital forensic examination of the m57-jean disk image to investigate unauthorized disclosure of confidential company salary spreadsheets.

Download Full Forensic Report (PDF)

// 01. Forensic Methodology & Artifact Extraction

01. Partition & Volume Analysis

Used mmls to inspect the partition table layout, locate unallocated spaces, and identify the primary NTFS data partition offset.

02. File System Inspection

Executed fsstat to extract NTFS metadata, cluster size, MFT structure, and volume serial details.

03. Directory & File Listing

Utilized fls and metadata timeline analysis to trace user files, recent documents, and Outlook PST archives.

04. Email & Chat Forensics

Extracted Outlook emails using readpst and correlated timestamps with AIM chat logs to establish intent and exfiltration method.

// 02. Executive Summary of Findings

  • Attack Vector: Employee Jean received a targeted spear-phishing email impersonating the CEO requesting urgent employee compensation data.
  • Exfiltrated Artifact: The confidential spreadsheet file (m57biz.xls) was located and verified within the user's local directory and Outlook sent items.
  • Corroborating Evidence: AIM instant messaging logs confirmed timeline correlation between receiving the deceptive request and transmitting the attachment externally.
