Network Traffic Analysis: Infected Windows Client Artifacts

Forensic packet inspection of 2026-02-28-traffic-analysis-exercise.pcap using Wireshark protocol dissectors (DHCP, Kerberos, SAMR, and Ethernet) to attribute network activity and profile the compromised Windows endpoint.

// 01. Forensic Methodology & Protocol Dissection

01. Endpoint & Layer-2 Correlation

Inspected Wireshark Conversations and Ethernet II headers to isolate the active internal client IP and extract its hardware MAC address.

02. DHCP Hostname Extraction

Filtered dhcp packets and examined DHCP Request (Option 12) fields to recover the target workstation's NetBIOS hostname.

03. Kerberos Account Attribution

Dissected kerberos AS-REQ messages to extract the CNameString principal identifying the logged-in domain user account.

04. SAMR Identity Verification

Searched SAMR (Security Account Manager Remote) QueryUserInfo responses to confirm the user's full registered name.
